# Fotos dels capítols

Si hi poses una foto amb el nom de l'`id` del capítol (`src/data/levels.json`), apareix com una polaroid a la pantalla de resultats d'aquell capítol. Si no hi és, no es mostra res.

Noms: `baby`, `toddler`, `moto`, `school`, `snow`, `nature`, `skate` (`.jpg`, `.jpeg`, `.png` o `.webp`). Per exemple: `assets/photos/snow.jpg`.

Atenció: el repositori i la web de GitHub Pages són públics. Tot el que es posi aquí es publica. Fes servir fotos petites (uns 600 px d'amplada) i sense dades personals.
